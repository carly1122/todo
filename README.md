# 📝 待办清单（Todo List）

一个简洁美观的待办事项网页应用。纯前端单文件实现，无需安装任何东西，打开浏览器就能用。

在线体验：https://carly1122.github.io/todo/

## ✨ 功能

- 添加任务（回车或点按钮）
- 勾选完成，自动带删除线并沉到列表底部
- 双击任务文字可直接修改
- 删除单个任务
- 一键清除已完成
- 清空全部（两步确认，防误删）
- 深色 / 浅色主题切换，记住你的选择
- 所有数据保存在浏览器本地（localStorage），关闭页面不丢失

## 🚀 使用方法

下载 `index.html`，双击用浏览器打开即可。

## 🛠 技术

- 单个 HTML 文件，内联 CSS + JavaScript
- 数据存储：浏览器 localStorage
- 无任何依赖和构建步骤
